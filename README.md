# Personal Expenses App

A Flutter practice app for entering dated expenses and seeing how much you spent over the past week. Enter an amount and date, review the transaction list, and compare daily totals in a seven-day bar chart.

## Explore the code

Explore [the transaction form](lib/tx_form.dart), [the expense list](lib/list_of_expenses.dart), and [the chart](lib/chart.dart). Expenses are kept in memory for the current session.

## Run locally

Use a Flutter SDK that satisfies the Dart 2 constraint in [`pubspec.yaml`](pubspec.yaml).

```sh
flutter pub get
flutter run
```
